# Embedded font provenance

The generated native pages embed Nimbus Sans Regular and Nimbus Sans Bold supplied by MuPDF/PyMuPDF. These belong to Artifex/URW Base35. Upstream license and PDF embedding exception are preserved in FONT-LICENSE.txt; the full AGPL text is in the repository LICENSE.

Source: https://github.com/ArtifexSoftware/urw-base35-fonts
License: https://github.com/ArtifexSoftware/urw-base35-fonts/blob/master/LICENSE

No separate system fonts or downloaded fonts are used. Scanned pages rasterize the same original content.
